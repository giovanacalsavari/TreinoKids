# Meu Treino Kids

Site PWA para acompanhar treinos supervisionados em família. Três dias principais e dois opcionais, com musculação leve e cardio em blocos curtos.

## Publicar no GitHub Pages
1. Crie um repositório público `meu-treino-kids`.
2. Envie os arquivos desta pasta para a **raiz** do repositório (não envie apenas o ZIP).
3. Em Settings → Pages, selecione Deploy from a branch → main → /(root) e salve.
4. Aguarde a publicação e acesse `https://SEU-USUARIO.github.io/meu-treino-kids/`.
5. No Chrome Android, use o menu → Instalar aplicativo ou Adicionar à tela inicial.

O app pode funcionar offline após a primeira visita online. As marcações, anotações e cargas são guardadas localmente no navegador; não são sincronizadas entre dispositivos. Limpar dados do navegador pode apagá-las.

**Saúde:** conteúdo educativo, não substitui avaliação pediátrica e supervisão de profissional de Educação Física com experiência em crianças. Cargas, máquinas e volume devem ser adaptados individualmente.
